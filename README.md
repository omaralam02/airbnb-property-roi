
# Airbnb Property ROI
## Dataset
[Airbnb Property ROI](https://github.com/omaralam02/airbnb-property-roi/blob/main/Airbnb%20Property%20ROI.xlsx)

## Project Objective
Find out the Return on Investment of renting a property in Airbnb in New York.

## Process
•	Explored the data using advance formulas and formatting
•	Used analytics tools to forecast potential earnings
•	Created charts and PivotTables to supplement the analysis.
